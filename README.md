# Sentinel Prompt Lab

A dependency-free defensive prompt engineering simulation for cyber security learners. It includes prerequisite instruction, an interactive prompt forge, twelve progressively harder levels with hints and unlimited retries, AI-output auditing, an expert final prompt assessment and downloadable certificate.

The student reference guide is provided as `Prompt-Engineering-Instructions.pdf`.

Open `index.html` directly or publish with GitHub Pages. All interactions are local simulations; no prompts or learner data leave the browser. Progress is stored in `localStorage`.
