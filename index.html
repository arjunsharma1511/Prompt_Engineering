The five-part defensive prompt

AI output is a suggestion, not verified evidence. A useful security prompt makes the task bounded, the supplied data explicit and the result easy for a human to check.

Role

State the perspective and limits: “You are assisting a Level 1 SOC analyst.”

Task

Ask for one clear defensive outcome: summarise, compare, identify gaps or draft questions.

Permitted data

Use only supplied fictional or approved data. Say not to invent missing facts.

Format

Request headings, tables or bullets so claims and evidence are easy to review.

Uncertainty

Require unknowns, alternatives, validation steps and confidence limits.

ROLE+TASK+DATA+FORMAT+UNCERTAINTY= REVIEWABLE OUTPUT

AI can help with

  • Summaries and timelines
  • Investigation questions
  • Alternative explanations
  • Draft report structure
  • Terminology explanations

Human must still

  • Verify against original telemetry
  • Protect sensitive information
  • Follow authority and policy
  • Own escalation decisions
  • Correct hallucinations and omissions

Do not request

  • Invented facts or fake certainty
  • Unnecessary attack instructions
  • Secrets or protected personal data
  • Automatic disruptive actions
  • Conclusions without evidence
